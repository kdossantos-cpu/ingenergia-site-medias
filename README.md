# ingenergia-site-medias

Images destinées au site https://www.ingenergia.fr/ — dépôt **public** de transit : WordPress télécharge ici les fichiers pour les ajouter à sa médiathèque.

Règles (décision KDS du 12/11/2026) :
- uniquement des images déjà publiques (LinkedIn, site) ou validées pour publication ;
- aucun visage reconnaissable autre que celui du dirigeant, aucun nom de client, aucune donnée personnelle ;
- une seule personne écrit ici : l'agent du site, à partir du champ VISUEL validé d'une carte ;
- noms de fichiers descriptifs, WebP, 3:2 ou 16:9, 1200 px de large au plus.
